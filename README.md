anteenGo is a smart campus canteen system that helps students order food and avoid long queues.

Features
🍔 View food menu
🔍 Search food items
📂 Filter food by category
🛒 Add and remove items from cart
💰 Calculate total price
🎟️ Generate digital order token
📊 View canteen dashboard
👨‍🍳 Manage orders
⭐ Give feedback and ratings
🍽️ View canteen crowd status
Technologies Used
HTML
CSS
JavaScript
How to Run
Download or clone the repository.
Open index.html in a web browser.
Start ordering food.
